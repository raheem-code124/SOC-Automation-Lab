# SOC Automation Lab

## Overview
This repository documents my hands-on SOC automation home lab, following the MyDFIR SOC Automation Project tutorial series. The goal is to gain practical experience in security monitoring, threat detection, incident response, and security automation.

## Technologies
- Wazuh SIEM
- Sysmon
- Shuffle SOAR
- TheHive
- VirusTotal
- Windows and Linux

## Project Objectives
- Build and configure a virtual SOC environment.
- Collect and analyze endpoint security events.
- Create and test custom detection rules.
- Automate alert enrichment and incident case creation.
- Document the setup, testing, troubleshooting, and lessons learned.
