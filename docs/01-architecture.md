# SOC Lab Architecture

## Objective
Design and document the architecture of my SOC Automation Lab based on the MyDFIR tutorial series.

## Planned Components
- Windows VM: Endpoint for generating and collecting security events.
- Sysmon: Collects detailed Windows system activity.
- Wazuh: SIEM for log analysis and security alerting.
- Shuffle: SOAR platform for security workflow automation.
- TheHive: Incident case management platform.
- VirusTotal: Threat intelligence enrichment.
